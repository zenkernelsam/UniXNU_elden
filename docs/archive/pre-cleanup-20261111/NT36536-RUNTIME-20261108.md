# Elden NT36536：离线物理触控接入

本工单接续已验的虚拟 Home 和日用 iPad 计划。平板继续留在 Android 充电，本轮没有设备操作。
真实触控仍未验收；编译、静态 ABI 和协议检查分别记录。

源于 h0cheung 同机 Linux `6f97250ead155fc3b980856323e99a4623dae73d`：
NT36536、SPI4@a90000、wrapper1@ac0000、GPIO48..51、触控 GPIO162。
SPI pins 6mA/bias-disable，IRQ pin 8mA/pull-up；面板 reset GPIO98 保持。
GCC S4 RCG183dc/branch183cc、vote52008 的18/19/20/21/26位；共享 RCG，使用19.2MHz TCXO、SPI<=9.6MHz。

`Protocol`完整校验原 firmware，SRAM长度为size+1；校验ILM/DLM两个真实word CRC，
按原厂reset/trim/CRC/cascade auto-copy/boot-ready/PID6097顺序执行。没有flash/provision命令。
`Platform`在GENI时钟可读后核idle/FIFO/GPI归属，成功后才改本地时钟/pin/PIO配置。
正常退出按保存配置恢复；clock/update/transport或归还不确定则保留映射/租约隔离至整机复位。
当前没有GPI/SE-DMA接管；FIFO-disabled或活动GPI拒绝。后续DMA必须先取实机stream/bank证据。

原生HID继续使用canonical ShengHidInput `5f3a37ce`、原207-slot/208B IOHIDDevice ABI。
独立digitizer接已归一化0..32767坐标，禁止二次缩放，边缘范围改为Y7001904×3040。
原21H461私有表通过metaclass initializer和getter反向恢复：EventDriver220槽、Event37槽。
物理适配把上游256槽copy收窄为220；只有精确原vptr身份才安装dispatch198边缘hook，
事件同样核原vptr后才读取children/调用18/23/24/25槽。原Apple执行代码保持。

构建选项：`ELDEN_HID_BUILD=1 ELDEN_TOUCH_HID_BUILD=1 ELDEN_HID_PHYSICAL_TOUCH=1`；
物理SPI另加`ELDEN_TOUCH_RUNTIME_BUILD=1`。原firmware由显式输入生成到忽略的build目录，不提交。
硬件boot参数：`elden-touch=0`无物理动作，1运行态ID，2原firmware SRAM上传，3真实HID；
`elden-touch-hid=1`只启独立digitizer。默认均关闭，旧Home/USB/180秒panic与RPC回程保持。

真实输入每8ms读完整点报告，短IRQ脉冲不作为丢点/抬指依据；有效空帧或显式错误才释放旧接触。
坏帧3次停止，传输失败直接隔离，无自动重试。touch sink跨回调retain，锁外发布，避免对象生命周期竞态。

当前协议1890项、clock/pin/PIO故障模型ASan/UBSan通过；其中轮询边界重复断言不等于独立测试用例。
完整Mac/iOS17编译、重链和预链接已通过；五档独立签名候选已备，全部未刷。
新核2d8cd9e7…/52527208B，原207槽/52绑定和30执行模块身份通过（保留原AMFI诊断单字），
原FD/shim/56MiB FAT/ADT/trust/RAM Data/6GiB/8秒与180秒/RPC保持。
